## 最大似然和最大后验概率有什么区别

两者都是参数估计方法，核心区别在于**是否考虑先验信息**。

**1. 最大似然估计 (Maximum Likelihood, ML)**
*   **核心思想**：找到使观测数据出现概率最大的参数值。
*   $$\hat{\theta}_{ML} = \arg\max_{\theta} P(X|\theta)$$
*   只考虑**似然函数** $P(X|\theta)$，即“给定参数 $\theta$，观测到数据 $X$ 的概率”。
*   **不使用任何先验知识**，完全由数据驱动。
*   隐含假设：所有参数值在先验上是等可能的（均匀先验）。

**2. 最大后验概率估计 (Maximum A Posteriori, MAP)**
*   **核心思想**：找到在观测数据条件下，后验概率最大的参数值。
*   $$\hat{\theta}_{MAP} = \arg\max_{\theta} P(\theta|X) = \arg\max_{\theta} \frac{P(X|\theta) P(\theta)}{P(X)}$$
*   等价于：$$\hat{\theta}_{MAP} = \arg\max_{\theta} P(X|\theta) P(\theta)$$
*   同时考虑**似然函数**和**先验概率** $P(\theta)$。
*   **融合了先验知识**，当先验是均匀分布时，MAP 退化为 ML。

**3. 关键对比**

| 特性 | ML | MAP |
| :--- | :--- | :--- |
| **先验 $P(\theta)$** | 不考虑（或假设均匀） | 显式使用 |
| **数据量少时** | 容易过拟合 | 先验起正则化作用 |
| **数据量大时** | 两者趋于一致 | 两者趋于一致 |
| **贝叶斯视角** | 频率派方法 | 贝叶斯方法的点估计 |

**4. 通信中的例子**
在 Turbo 码译码中：
*   **ML 译码**：$\hat{c} = \arg\max_c P(r|c)$，只考虑接收信号 $r$ 在给定码字 $c$ 下的似然。
*   **MAP 译码**：$\hat{c} = \arg\max_c P(c|r) \propto P(r|c)P(c)$，还考虑码字的先验概率。
*   当信息比特等概率时，MAP 和 ML 等价；但如果先验不均匀，MAP 能利用这个信息获得更好的性能。

## bcjr和viterbi软判决的曲线为什么重合

*   **理论等价性**：BCJR 基于最大后验概率 (MAP)，由于通常假设先验是均匀分布等概的，而 Viterbi 基于最大似然 (ML)，当先验是均匀分布时，二者在性能上等价。
*   **信道模型一致**：数据输入解码器时都是软信息。在软判决 Viterbi 中计算欧式距离平方利用了 AWGN 信道的 PDF，而 BCJR 的信道度量（Gamma）的信道观察同样基于 AWGN 信道的 PDF。两者都充分利用了信道的统计特性。

## 为什么叫自由距离不叫汉明距

**1. 码长不固定（“自由”的来源）**
*   **分组码 (Block Codes)**：汉明距离 ($d_H$) 定义在固定长度 ($n$) 的码字之间。最小汉明距离 $d_{min}$ 是在有限向量空间里寻找。
*   **卷积码 (Convolutional Codes)**：理论上序列可以无限长。由于没有固定“码块”限制，两条路径可以在格图 (Trellis) 中任意位置分叉，经过一段路径后再重新汇合。
*   **结论**：这种在格图中“自由”分叉又“汇合”产生的最小距离称为“自由距离”，强调它是任意长度序列比较中的最小值。

**2. 格图中的路径特性**
*   **自由距离定义**：指在格图中，所有从全零状态出发、并在稍后时刻首次回到全零状态的非全零路径中具有的最小汉明重量。
*   **特性**：这种定义依赖于状态转移的动态过程，而不是静态的向量对比。

**3. 性能衡量指标的区分**
*   **分组码**：用 $d_{min}$（最小距离）衡量。
*   **卷积码**：用 $d_{free}$（自由距离）衡量。它是 Viterbi 译码在高信噪比条件下决定误码率上限的关键参数。

**4. 总结对比**

| 特性 | 分组码的最小距离 ($d_{min}$) | 卷积码的自由距离 ($d_{free}$) |
| :--- | :--- | :--- |
| **度量基础** | 汉明距离 (Hamming Distance) | 汉明距离 (Hamming Distance) |
| **长度约束** | 固定码长 $n$ | 无约束（序列可无限长） |
| **结构视角** | 向量空间中的分布 | 格图中路径的分离与汇合 |
| **物理含义** | 两个固定码字间最少不同的位 | 两条自由路径间最少不同的位 |

**一句话总结**：卷积码的“自由距离”就是序列长度不受限（自由）时的最小汉明距离。使用特殊术语是为了强调卷积码“流式”编码与分组码“块状”结构的区别。

## 打孔对 ber 曲线的影响

*   **物理本质**：打孔（Puncturing）实际上是人为地删除了 RSC (Recursive Systematic Convolutional) 编码器输出的部分校验位。
*   **性能影响**：这会导致码率（Rate）提高，但由于传输的冗余信息减少，BER 曲线在相同信噪比下会发生恶化（向右偏移）。

## 如何清零 (Trellis Termination)

*   **非系统码**：
    *   处理较为简单。如果编码器有 $m$ 个寄存器，只需在信息序列末尾补 $m$ 个“0”，即可使寄存器状态强制回到全零状态。
*   **系统码 (如 RSC)**：
    *   由于存在反馈回路，直接补零无法保证清零。
    *   **实现方法**：需要通过查状态转移表或实时记录反馈（Feedback）值。让输入比特 $u$ 等于当前的反馈值（即 $u \oplus \text{Feedback} = 0 \Rightarrow u = \text{Feedback}$），持续 $m$ 个时钟周期。这样每个周期都会抵消反馈影响，直到 $m$ 个寄存器状态全部归零。


## BCJR和维特比的本质区别

**1. 核心准则：序列 vs 比特**
这是两者最根本的区别。
*   **维特比算法 (MLSE)**：
    *   **目标**：寻找概率最大的路径（序列）。
    *   **数学本质**：最大似然序列估计（Maximum Likelihood Sequence Estimation）。在所有可能的路径中，找一条与接收序列距离最近（似然度最大）的整体路径。
    *   **代价函数**：最小化序列错误率（FER/WER）。即只要路径上有一个比特错了，整个序列就算错。
*   **BCJR 算法 (MAP)**：
    *   **目标**：寻找每个时刻概率最大的比特（符号）。
    *   **数学本质**：最大后验概率（Maximum A Posteriori）。计算每一个比特 $u_k$ 在给定整个接收序列 $y$ 条件下的后验概率 $P(u_k | y)$。
    *   **代价函数**：最小化比特错误率（BER）。它不关心路径是否整体正确，只求每个点上的决策最稳。

**2. 算法结构：回溯 vs 前后向循环**
由于目标不同，两者的实现逻辑完全不同。
*   **维特比（向前递推 + 回溯）**：采用 ACS (Add-Compare-Select) 操作。在每个时刻，每个状态只保留一条“幸存路径”。当处理完整个数据块后，从终点开始进行回溯 (Traceback)，从而确定最优路径。
*   **BCJR（前向循环 + 后向循环）**：为了计算某个时刻 $k$ 的后验概率，它不仅需要前向信息（$\alpha$），还需要后向信息（$\beta$）。
    *   **流程**：先做一遍前向扫描（计算 $\alpha$），再做一遍后向扫描（计算 $\beta$），最后结合分支转移概率（$\gamma$）在每个时刻合并计算。

**3. 输出形式：硬判决 vs 软输出**
*   **维特比**：标准维特比输出“0”或“1”的硬判决序列。虽有变种（如 SOVA）可输出软信息，但仅是 BCJR 的一种近似。
*   **BCJR**：天然输出软信息（通常是对数似然比 LLR）。它能提供置信度：“这个比特是 1 的概率是 0.9，是 0 的概率是 0.1”。

**4. 性能与复杂度对比**

| 特性 | 维特比 (Viterbi) | BCJR (MAP) |
| :--- | :--- | :--- |
| **优化目标** | 最大化序列概率 (MLSE) | 最大化单个比特概率 (MAP) |
| **错误率控制** | 最小化 FER (帧错误率) | 最小化 BER (比特错误率) |
| **计算复杂度** | 较低（仅前向 + 回溯） | 较高（约是 Viterbi 的 3-4 倍） |
| **存储需求** | 较小（存储路径度和回溯位） | 很大（需存储整帧前向度量 $\alpha$） |
| **典型应用** | 卷积码译码、GSM 均衡 | Turbo 码译码、迭代接收机 |

**总结**：维特比是一个“顾全大局”的算法，在格图中通过剪枝找到一条最合理的路径；而 BCJR 是一个“精益求精”的算法，利用所有已知信息对每个比特深度权衡。由于 Turbo 码需要交换“软信息”进行迭代，BCJR 是其接近香农极限的数学基石。

## 自由距离的概念

对卷积码而言，任意两个有效码字之间的最小汉明距离称为自由距离。 具体而言，一个卷积码的自由距离等于全零路径与从状态00重新回到状态00的最小非零路径之间的路径度量之差。
